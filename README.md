# 📊 RETAILPULSE – Inventory Health Dashboard

## 📌 Project Overview

RetailPulse is an interactive Inventory Health Dashboard developed using Microsoft Power BI. This project helps analyze inventory performance, monitor stock availability, identify low-stock products, and track inventory value. It provides meaningful insights through interactive visualizations and key performance indicators (KPIs).

## 🎯 Project Objectives

- Monitor overall inventory performance.
- Identify low-stock and out-of-stock products.
- Analyze inventory value by product category.
- Compare available stock with reorder points.
- Track incoming stock and daily product demand.
- Support effective inventory planning and decision-making.

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard development and data visualization.
- **Microsoft Excel** – Dataset management.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculations, measures, and KPIs.

## 📈 Key Dashboard Features

- Total On-Hand Units
- Total Inventory Value
- Total On-Order Units
- Days of Inventory Cover
- Inventory by Category
- Inventory Value by Category
- On-Hand Stock vs Reorder Point
- Low-Stock and Out-of-Stock Product Analysis
- Interactive Category and Product Filters

## 📂 Dataset Information

The dataset contains the following fields:

- StockCode
- Description
- Category
- On Hand Units
- On Order Units
- Unit Cost
- Reorder Point
- Daily Demand

*Note: The dataset is illustrative and used for learning and portfolio demonstration purposes.*

## 💡 Key Insights

The dashboard helps users understand stock availability, identify products that need replenishment, evaluate inventory value, and monitor stock coverage based on daily demand.

## 🚀 Project Outcome

This project demonstrates practical knowledge of data cleaning, data transformation, data modeling, DAX calculations, KPI creation, and interactive dashboard development using Power BI.
